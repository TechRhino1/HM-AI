8 · Cross-page navigation

The three content pages marked the current link with btn-nav-active, while the India pages used bare active — two conventions for one concept. The design system styles both plus the canonical aria-current="page", so the markup no longer has to agree with the stylesheet.

⚡ Forex / Crypto 🇺🇸 US Stocks 🇮🇳 India Stocks 📊 India Options (F&O)

Both the 2nd link (btn-nav-active) and the 4th (active) render identically — demonstrating the divergence is now harmless.

9 · Mobile tab bar

Forced visible here for review (it is display:none above 900 px). Each tab is now a 44 px minimum target — the previous padding produced roughly 28 px, below the usable threshold for touch. Arrow keys move between tabs.

11 · Feedback — toasts

Ten blocking window.alert() calls become non-modal toasts, with no edits to the call sites: the layer swaps window.alert for a shim that infers severity from the existing wording. The original message text, including its newlines, is preserved.

These fire through the real HMUI.toast() API used by the shim, so the stack, animation, auto-dismiss and dismiss button are the production behaviour.

12 · Dialog & focus management

Opening this dialog traps focus inside it, closes on Escape, locks background scroll, and restores focus to this button on close. The three production modals (#command-palette-overlay, #macro-news-modal, #remote-login-modal) get the same behaviour automatically, because the layer observes their inline style.display toggles rather than requiring a rewrite.

13 · Focus ring

The four page sheets contain eight outline: none declarations and none of them restored an indicator — a WCAG 2.4.7 failure. A single :focus-visible rule reinstates it for keyboard users only, so mouse clicks stay clean.

14 · Reduced motion

With prefers-reduced-motion: reduce set at the OS level, the pulse dot, toast slide-in and all transitions collapse to effectively zero duration. Toggle it in your OS accessibility settings and reload to verify.
